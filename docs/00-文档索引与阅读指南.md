## 文档组织原则

- 文档集按职责边界组织；每份文档只规定一类主题，并在其职责范围内作为唯一规范来源。
- 第 7 章按能力分为“库存与单据流程”“XLSX 快速录入与导出”；7.9 的 MCP 原子建单与第 8 章 8.6 同属 MCP 能力，合并为“MCP 服务与工具”。第 8 章其余内容按接口面分为“通用约定与健康检查”“账户、基础资料与系统维护 API”“单据与库存业务 API”。
- 文档集统一使用章、节编号；跨文档引用使用链接；同一规则只在职责文档中定义，其他文档引用而不重复。
- 本索引不承载规范正文；规范内容以各职责文档为准。

## 交叉引用与编号约定

- 文档集统一使用章、节编号（如 `6.4`、`7.9`、`10.7`），便于跨文档检索和验收追踪。
- 跨文档引用采用“《文档短名》X.Y”文字加“相对路径#锚点”目标的 Markdown 链接；同一文档内的引用保留原编号，不重复加文档名。
- 第 7、8 章的相关主题分布在多个职责文档中；按本文的“章节—文档索引”定位。
- 需求追踪矩阵中的“设计章节”编号与本文档索引一致；按编号可在对应文档中定位。
- 链接锚点按标题生成；若渲染环境不支持中文锚点，可退回文件级链接，章节编号本身仍可直接检索。

- 文档版本或职责边界变化时，应同步更新相关文档的版本标识、交叉引用和本索引。
